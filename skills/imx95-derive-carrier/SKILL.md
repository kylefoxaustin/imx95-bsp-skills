# imx95-derive-carrier

## Purpose

Create a custom carrier board device tree overlay by forking the FRDM-IMX95 base DTS.
Scaffolds the overlay directory structure, creates the initial `.dts` file with the correct
`#include` of the base DTS, and registers the overlay in the `linux-imx_%.bbappend` recipe.

## When to Invoke

- User has a custom carrier board (not the stock FRDM-IMX95 EVK)
- User says "create custom carrier", "fork the device tree", "custom board DT"
- After `imx95-init-source`, before any hardware-specific customization

## Pre-conditions

1. `targets/active_target.yaml` exists.
2. `sources/meta-imx95-custom/` exists (created by `imx95-init-source`).
3. `overlay-tracker/` git repo is initialized.

## Questions to Ask User

Before generating any files, ask:

1. **Carrier board name** — short slug, no spaces (e.g., `acme-carrier-v1`)
   Used as the overlay file prefix: `imx95-<carrier-name>.dts`

2. **Base DTS to fork from** — which FRDM-IMX95 DTS to use as the base:
   - `imx95-19x19-lpddr5-evk.dts` (default — 19×19 EVK)
   - `imx95frdm.dts` (FRDM-IMX95 Freedom board)
   - `imx95-15x15-evk.dts` (15×15 EVK)

3. **Company/copyright holder** — for the SPDX header

4. **Does the carrier reuse the FRDM SOM?**
   - Yes → overlay only needs to override carrier-specific nodes
   - No → full custom board (more extensive overlay needed)

## Procedure

### Step 1 — Read active target

Extract `paths.dt_overlay_dir` and `paths.custom_layer` from `targets/active_target.yaml`.

### Step 2 — Generate overlay files

Run:
```bash
bash skills/imx95-derive-carrier/scripts/derive_carrier.sh \
    --carrier-name <name> \
    --base-dts <base-dts-file> \
    --company "<Company Name>"
```

This creates:
```
sources/meta-imx95-custom/recipes-kernel/linux/files/overlays/
  imx95-<carrier-name>.dts          ← Main carrier overlay
  imx95-<carrier-name>-pinmux.dts   ← Pinmux sub-overlay
```

### STOP — Show generated files to user

Display the complete content of both generated `.dts` files.
State: "Here are the generated overlay files. Please review and reply 'approve' to write
them to disk, or tell me what to change."

Wait for explicit approval before writing.

### Step 3 — Write files to disk

After approval, write the files to `dt_overlay_dir`.

### Step 4 — Update bbappend

Add `SRC_URI` entries to `linux-imx_%.bbappend`:
```
SRC_URI += "file://overlays/imx95-<carrier-name>.dts"
SRC_URI += "file://overlays/imx95-<carrier-name>-pinmux.dts"
```

### Step 5 — Update active target YAML

Set `board.custom_carrier: true` and `custom_carrier.carrier_name: <name>` in
`targets/active_target.yaml`.

### Step 6 — Commit to overlay-tracker (commit-gate)

Stage the new files:
```bash
cd overlay-tracker/
git add ../sources/meta-imx95-custom/recipes-kernel/linux/files/overlays/imx95-<name>.dts
git add ../sources/meta-imx95-custom/recipes-kernel/linux/files/overlays/imx95-<name>-pinmux.dts
git add ../sources/meta-imx95-custom/recipes-kernel/linux/linux-imx_%.bbappend
git diff --staged
```

**STOP — show complete diff, wait for approval, then commit.**

Commit message:
```
customize(carrier): scaffold imx95-<carrier-name> overlay

Board: <profile_name>
Skill: imx95-derive-carrier
Files: imx95-<carrier-name>.dts, imx95-<carrier-name>-pinmux.dts,
       linux-imx_%.bbappend

Initial carrier overlay forked from <base-dts>.
Carrier: <carrier-name>

Tested: pending
```

### Step 7 — Report to user

Print:
- Files created
- Overlay-tracker commit SHA
- Recommended next steps: `imx95-customize-pinmux`, `imx95-customize-usb`, etc.

## Overlay File Template

```dts
// SPDX-License-Identifier: GPL-2.0+
/*
 * Copyright (C) <YEAR> <Company>
 * Custom carrier board overlay for NXP i.MX 95
 * Base: <base-dts>
 *
 * Generated by imx95-bsp-skills / imx95-derive-carrier
 */

/dts-v1/;
/plugin/;

#include <dt-bindings/gpio/gpio.h>
#include <dt-bindings/clock/imx95-clock.h>
#include "imx95-19x19-lpddr5-evk.dts"

/ {
    model = "NXP i.MX95 <Carrier Name>";
    compatible = "nxp,imx95-<carrier>", "nxp,imx95";
};

/* ── Carrier-specific node overrides ─────────────────────────────────────── */
/* Add &node { ... }; overrides below as hardware is configured.             */
/* Use imx95-customize-pinmux, imx95-customize-usb, etc. for guided edits.  */
```
